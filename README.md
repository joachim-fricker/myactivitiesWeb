# myactivitiesWeb – My Activities (Windows)

Native Windows-App (WPF, .NET 10, WPF-UI) zur Anzeige der Garmin-Aktivitäten
aus https://github.com/joachim-fricker/myactivities mit Fotos aus `C:\Data\Images`.

## Bauen
1. Visual Studio 2026 Community mit Workload ".NET-Desktopentwicklung"
2. `src/MyActivities/MyActivities.csproj` öffnen, F5

## Geplante Funktionen
- Jahresstatistik (km / Höhenmeter pro Typ und Jahr)
- Filter- und sortierbare Aktivitäten-Tabelle mit Track
- Karte mit Startpunkten und GPX-Tracks
- Fotos zur Aktivität (Zuordnung über Aufnahmezeit im Dateinamen)
